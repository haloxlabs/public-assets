# HaloX Public Assets

Public image and media assets for HaloX content operations.

## Purpose

This repository is for public, non-sensitive assets that need stable HTTPS URLs for:

- Notion pages
- lecture and workshop materials
- WikiDocs/public docs embeds
- landing/detail-page proof images
- Slack-shareable visual references

## Rules

- Only upload assets that are safe to be public.
- Do not upload customer data, credentials, private screenshots, or production account information.
- Prefer descriptive folder paths and filenames.
- Use this repo when a stable public URL is explicitly needed. If the target supports native upload, use native upload first.

## Current structure

```text
notion/        Notion page embeds and temporary stable public URLs
lectures/      Workshop and lecture material images
wikidocs/      WikiDocs/public article visuals
landing/       Landing/detail-page visuals
```

## URL pattern

```text
https://raw.githubusercontent.com/haloxlabs/public-assets/main/<path>
```
